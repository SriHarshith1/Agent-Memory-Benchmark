Agent Memory Benchmark

Mem0 leads accuracy at 81.0% and recall at 93.3%. Zep (Graphiti) leads precision at 90.9% and has the fewest stale answers at 16.7%. Mem0 and Zep (Graphiti) still return a deleted fact for some users. Independent benchmark of long-term memory for AI agents, on 3 synthetic users and 21 questions per system. Open source. Last measured 20 Nov 2026.

Why we built this. A memory layer has three jobs: remember what the user said, keep up when it changes, and forget what the user asks it to forget. Public comparisons of memory vendors argue about judging method. This board uses template data with an exact answer key, so every score can be checked by hand.

Model-only baseline. With no memory, the agent scores 28.6% accuracy, and every point comes from correctly saying UNKNOWN. Its recall is 0.0%. Putting the whole history in the prompt scores 85.7%, but the prompt grows with every session, and a long history can bury a forget request.

How it is measured. The answering agent, its prompt and the scorer stay the same for every system, so the comparison isolates the memory layer.

How to read this. Start from the situation that matches your product, then read that row.

  • Remember. Read plain recall and someone else's fact.
  • Keep up. Read updated fact. A stale answer counts as a failure.
  • Forget. Read deleted fact. The right answer is UNKNOWN.

[01.a] methodology and metric definitions

How the board is built

  1. Generate users from templates with a fixed seed. Every answer key is exact.
  2. For each system: reset the user, then ingest each session in time order.
  3. For each question: retrieve memories, then pass them to one fixed agent (qwen3.5 via Ollama, temperature 0, thinking off).
  4. The agent replies with a short answer or exactly UNKNOWN. Scoring is normalized exact match. No LLM judge.
  5. The agent is not told to respect forget requests. Deleting a fact is the memory system's job, so the deleted-fact row measures the memory system alone.

What each metric means

  • Accuracy · correct ÷ all questions. UNKNOWN on an unanswerable question counts as correct.
  • Precision · correct answers ÷ all non-UNKNOWN answers.
  • Recall · correct answers ÷ questions that have a real answer.
  • F1 · harmonic mean of precision and recall.
  • Abstain · UNKNOWN replies ÷ questions whose answer is UNKNOWN.
  • Stale answers · replies equal to the outdated value ÷ questions that have one. Lower is better.
  • Ingest / retrieve time · wall time on one Mac with local models. Compare systems only within this board.

[02.a] how the dataset is built

Each user has a timeline of chat sessions. Four sessions carry facts, in this order. All other sessions are small talk.

  1. Intro · pet name, home city, work email.
  2. Sibling · the sibling's name and city (another person's facts).
  3. Move · the user moves to a new city and a new company.
  4. Forget · the user asks the assistant to forget the old work email.

Filler lines mention other cities as hard negatives. The old city, new city and sibling city are always different. A self-check rejects any user whose answer is missing from the text, or whose deleted email appears after the forget request.
